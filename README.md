# 📊 Telecom Customer Churn Analysis

## 📌 Project Overview

This project is an end-to-end **Telecom Customer Churn Analysis** project designed to analyze customer behavior and identify patterns associated with customer churn.

The project covers the complete data analytics workflow, starting from raw Excel data, followed by data cleaning and feature engineering using **Python and Pandas**, SQL analysis using **PostgreSQL**, and finally the development of an interactive **Power BI dashboard**.

The analysis focuses on customer churn, customer segmentation, contract types, subscription types, payment methods, internet services, tenure, and revenue.

---

## 🎯 Business Objective

The main objective of this project is to:

- Analyze the overall customer churn rate.
- Identify the number of churned and retained customers.
- Understand customer behavior across different segments.
- Analyze churn based on contract type, subscription type, internet service, payment method, and location.
- Calculate important customer and revenue-related KPIs.
- Build an interactive dashboard that helps users explore churn patterns.
- Generate insights that can support customer retention strategies.
